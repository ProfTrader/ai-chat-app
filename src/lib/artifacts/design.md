# Tradeify HTML Brief Design

## Brand Memory
- Client brand: Tradeify.
- Official site: https://tradeify.co/
- Official horizontal logo asset: https://cdn.prod.website-files.com/679b064a680c614548672a06/67b4273005993910d632c26d_horizontal-logo%20(1).svg
- Business context: futures prop firm, funded trader programs, payouts, risk control, account quality, and trader growth.
- Tone: premium operating dashboard for a prop firm leadership team. Confident, direct, evidence-led, and compliance-aware.

## Visual System
- Use Mona Sans or Inter-style sans typography.
- Use a dark base with sharp white content, Tradeify green accents, restrained gold highlights, and cool slate data surfaces.
- Primary colors:
  - Deep base: #050506
  - Panel: #0c1014
  - Elevated panel: #111114
  - Tradeify green: #03dc5d
  - Electric green: #00ff51
  - Gold accent: #d5a132
  - Cool slate: #132a3a
  - Mist text: #e9f0f5
  - Muted text: #9a9aa3
- Keep border radius tight, 8px or less.
- Use subtle borders, small glows, and chart accents. Avoid decorative blobs, oversized cards, or generic SaaS gradients.

## Artifact Layout
- First viewport should clearly signal Tradeify with the official logo or a text fallback.
- Header should feel like a branded executive report, not a marketing landing page.
- Prioritize charts, KPI cards, segment tables, evidence trails, and risk notes.
- Include payout, revenue, overhead, trader segment, account quality, worker KPI, and audit language when evidence supports it.
- Every large numeric claim must be linked to provided evidence or marked as assumption by the model.

## Agent Instructions
- Kimi writes the narrative from Nexus evidence only.
- Do not invent live Tradeify metrics, customer counts, payout figures, or competitor facts.
- If the user asks for competitive analysis and web research is not available in the app, state that external sourcing is required and keep the brief to internal mock data.
- HTML production should apply this design file after the markdown plan is approved.
- The evidence appendix must mention that design.md supplied the Tradeify brand treatment.
